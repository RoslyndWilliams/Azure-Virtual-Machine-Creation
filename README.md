# Azure Virtual Machine Setup for Small Business IT

This project demonstrates how small businesses—like dental clinics or consulting firms—can deploy remote IT infrastructure using Microsoft Azure.

## 🧠 Project Goals

- Show how to create a secure, cloud-based Windows virtual machine
- Support business use cases like remote employee access or centralized software hosting
- Highlight cloud skills relevant to tech sales, support, and pre-sales roles

## 🔧 What's Included

- Business use case overview
- Full setup walkthrough with screenshots (see `INSTALLATION.md`)
- Cleanup and cost-saving tips
